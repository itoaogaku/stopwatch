# ストップウォッチ Web アプリ

スタート・スプリット・ラップ・ストップに対応したブラウザだけで動くストップウォッチです。
記録はスプリット(累計タイム)とラップ(区間タイム)を1つの密な一覧に並べ、たくさんの記録を一目で確認できるレイアウトになっています。記録は CSV への書き出し、または Google スプレッドシートへの直接保存に対応しています。

## 機能

- **スタート / ストップ**: 計測の開始・一時停止(ストップ後は再度スタートで再開、リセットでクリア)
- **スプリット**: スタートからの累計タイムを記録
- **ラップ**: 直前のラップからの区間タイムを記録
- **記録一覧**: スプリット(SP)とラップ(LP)を新しい順に、複数カラムの密なグリッドで表示。件数が増えても折り返して並ぶのでスクロールを最小限に一覧できます
- **CSV保存**: その場でCSVファイルとしてダウンロード(Excel/Googleスプレッドシートにインポート可能)
- **スプレッドシートに保存**: Google スプレッドシートへ直接、新しい記録だけを追記

## 使い方(ローカルで開く)

Google サインインには `file://` ではなく `http(s)://` オリジンが必要なので、簡易サーバー経由で開いてください。

```bash
npx serve .
# または
python3 -m http.server 8080
```

ブラウザで表示された URL(例: `http://localhost:8080`)を開きます。

## Google スプレッドシート連携の設定

このアプリはサーバーを持たないため、あなた自身の Google Cloud プロジェクトで発行した認証情報を使います。以下の手順で準備してください。

1. **Google Cloud プロジェクトを作成**(または既存のものを使用)
   https://console.cloud.google.com/

2. **Google Sheets API を有効化**
   「APIとサービス」→「ライブラリ」→ `Google Sheets API` を検索して有効化

3. **OAuth 同意画面を設定**
   「APIとサービス」→「OAuth 同意画面」で外部/内部を選び、アプリ名などを入力(テストユーザーとして自分のGoogleアカウントを追加)

4. **OAuth クライアントID を作成**
   「APIとサービス」→「認証情報」→「認証情報を作成」→「OAuthクライアントID」
   - アプリケーションの種類: **ウェブアプリケーション**
   - 承認済みの JavaScript 生成元 に、アプリを開くURLを追加
     - 例: `http://localhost:8080`、GitHub Pages で公開する場合はそのURL
   - 作成後に表示される **クライアントID**(`xxxxx.apps.googleusercontent.com`)をコピー

5. **保存先のスプレッドシートを用意**
   Google スプレッドシートを新規作成し、URLの `.../d/【この部分】/edit` の部分が **スプレッドシートID** です。
   ログインするGoogleアカウントがそのスプレッドシートの編集権限を持っている必要があります(自分で作成すればOK)。

6. **アプリ側の設定**
   アプリ右上の ⚙ ボタンから設定画面を開き、以下を入力して保存します。
   - Google OAuth クライアントID
   - スプレッドシートID
   - シート名(既定は `シート1`。実際のシート名に合わせて変更してください)

7. **サインイン**
   設定画面の「Googleでサインイン」を押し、権限を許可します。

8. **保存**
   計測後、「スプレッドシートに保存」ボタンを押すと、まだ保存していない記録だけが末尾に追記されます(1行目が空ならヘッダー行も自動追加)。

設定値はブラウザの `localStorage` にのみ保存され、外部送信はされません。

## ファイル構成

- `index.html` — 画面構造
- `style.css` — デザイン(記録を多列グリッドで密に表示)
- `app.js` — 計測ロジック・記録管理・CSV/スプレッドシート連携
