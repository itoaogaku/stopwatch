# ストップウォッチ Web アプリ

スタート/ストップ・ラップに対応したブラウザだけで動くストップウォッチです。
1つのタイマーに対して A・B 2つの独立したラップ系列を記録でき、押すたびに区間タイム(直前のラップからの経過)と累計タイム(スタートからの経過)を同時に1件の記録として残し、密な一覧に並べます。たくさんの記録を一目で確認できるレイアウトです。

## 機能

- **スタート/ストップ**: 1つのボタンで開始・一時停止をトグル(ストップ後は再度押して再開、リセットでクリア)
- **Aラップ / Bラップ / 両方**: 押すたびに、区間タイムと累計タイムを同時に1件の記録として追加。A・Bはそれぞれ独立したラップ回数・区間タイムを持ち、「両方」を押すとA・B両方の記録を同時に1件ずつ追加します(2人同時計測やダブルスプリットなどに利用できます)
- **記録一覧**: 新しい順に、複数カラムの密なグリッドで表示。A/Bのラベルが色分けされ、件数が増えても折り返して並ぶのでスクロールを最小限に一覧できます
- **全ウォッチ最新**: 時計のLCD画面内に、AとBそれぞれのライブタイム(直前のラップからの経過)がありますが、計測中はそのすぐ下に、全ての親・子ストップウォッチ(自分自身含む)の同じレーン(A/B)での最新記録が一覧表示されます。Aのライブタイムの下にはA同士、Bのライブタイムの下にはB同士がまとまります。どれかのストップウォッチでラップを記録するたび、計測中の全ての時計の表示がリアルタイムに更新されます。止まっている間は表示されません
- **複製**: 「複製」ボタンで2つ目・3つ目…とストップウォッチを増やせます。計測中に複製すると、複製先もその時点の経過時間・計測中の状態・それまでのA/Bの記録を丸ごと引き継いで動き出します(以降は互いに独立して操作可能。片方でラップしてももう片方には影響しません)。「削除」で不要になったストップウォッチを閉じられます(最後の1つは削除できません)
- **親子関係**: 止まっている状態で複製すると、複製先は新しい独立した「親」になります。計測中に複製すると、複製先はその親の「子」として親のすぐ下に並びます(子をさらに計測中に複製しても、同じ親の下にまとめて並びます)。子は本体・ボタンの色が紺色になり、一目で子だと分かります
- **名前の変更**: 各ストップウォッチ左上の「ストップウォッチ 1」などのラベルをタップ/クリックすると直接書き換えられます。空にするとデフォルトの名前に戻ります
- **CSV保存**: その場でCSVファイルとしてダウンロード(Excel/Googleスプレッドシートにインポート可能)。ストップウォッチごとに個別に、A/Bの「レーン」列付きで保存されます
- **全てCSV保存**: ページ上部のボタンから、表示中の全ての親・子ストップウォッチの記録を1つのCSVにまとめて出力できます。「ストップウォッチ」列(名前)と「親子」列(親/子)が付き、画面表示と同じ並び順(親→その子たち→次の親…)で出力されます

## 使い方(ローカルで開く)

```bash
npx serve .
# または
python3 -m http.server 8080
```

ブラウザで表示された URL(例: `http://localhost:8080`)を開きます。`index.html` を直接ダブルクリックして `file://` で開いても動作します。

## ファイル構成

- `index.html` — 画面構造
- `style.css` — デザイン(記録を多列グリッドで密に表示)
- `app.js` — 計測ロジック・記録管理・CSV連携
