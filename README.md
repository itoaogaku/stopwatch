# ストップウォッチ Web アプリ

スタート/ストップ・ラップに対応したブラウザだけで動くストップウォッチです。
1つのタイマーに対して A・B 2つの独立したラップ系列を記録でき、押すたびに区間タイム(直前のラップからの経過)と累計タイム(スタートからの経過)を同時に1件の記録として残し、密な一覧に並べます。たくさんの記録を一目で確認できるレイアウトです。

## 機能

- **スタート/ストップ**: 1つのボタンで開始・一時停止をトグル(ストップ後は再度押して再開、リセットでクリア)
- **Aラップ / Bラップ / 両方**: 押すたびに、区間タイムと累計タイムを同時に1件の記録として追加。A・Bはそれぞれ独立したラップ回数・区間タイムを持ち、「両方」を押すとA・B両方の記録を同時に1件ずつ追加します(2人同時計測やダブルスプリットなどに利用できます)
- **記録一覧**: 新しい順に、複数カラムの密なグリッドで表示。A/Bのラベルが色分けされ、件数が増えても折り返して並ぶのでスクロールを最小限に一覧できます。画面には各レーン最新4件までを表示し、それより古い記録はA/B共通の「もっと見る」ボタン1つで(両方まとめて)展開できます(もう一度押すと折りたたみます)
- **各レーンの最新ラップ**: 時計のLCD画面内、AとBそれぞれのライブタイム(直前のラップからの経過)の下に、そのストップウォッチ自身の直近の記録(区間タイム・合計タイム)が表示されます。他のストップウォッチの記録は表示されません。止まっている間は表示されません
- **子複製**: 「子複製」ボタンを押すと、そのストップウォッチの子として複製できます。計測中・停止中どちらでも、その時点の経過時間・A/Bの記録を丸ごと引き継ぎ(計測中ならそのまま動き続けます)、元の親のすぐ下に並びます(以降は互いに独立して操作可能。片方でラップしてももう片方には影響しません)。「削除」で不要になったストップウォッチを閉じられます(最後の1つは削除できません)
- **親子関係**: 「子複製」で増やしたストップウォッチは常に「子」になり、元のストップウォッチの親(すでに子ならそのルートの親)のすぐ下に並びます(子をさらに子複製しても、同じ親の下にまとめて並びます)。子は本体・ボタンの色が紺色になり、一目で子だと分かります
- **親複製**: 1番最初のストップウォッチにのみ表示されるボタンです。計測中でも、「親複製」ボタンを押すと記録・時計とも一切引き継がない、完全に新しい独立の「親」を追加できます(子にはならず、元のストップウォッチが動き続けていても影響しません)
- **名前の変更**: 各ストップウォッチ左上のラベル(親のデフォルトは作成順に A, B, C…Z, AA, AB…、子のデフォルトは親の名前を使って「A-複製1」「A-複製2」…)をタップ/クリックすると直接書き換えられます。空にするとそれぞれのデフォルトの名前に戻ります
- **Excel保存**: その場で罫線・太字ヘッダー付きの `.xlsx` ファイルとしてダウンロード(そのままExcel/Googleスプレッドシートで開けます)。ファイル名は `20260101_153042_stopwatch_1.xlsx` のように日付(YYYYMMDD)と時刻(HHMMSS)から始まります。ストップウォッチごとに個別に、「No」(ラップ番号)を基準にAの区間タイム・合計タイム、Bの区間タイム・合計タイムが縦の列で分かれて並びます(片方のレーンにしか記録がないラップ番号は該当列が空欄になります)。タイムは画面表示の1/100秒(例: `00:00.00`)ではなく、四捨五入した1/10秒で、先頭の単位(時間があれば時間、なければ分)の余分な0を省いた形(例: `8:12.5`、1時間以上なら `1:05:23.4`)で出力されます
- **全てExcel保存**: 1番最初のストップウォッチの「子複製」ボタンの左に並ぶボタンから、表示中の全ての親・子ストップウォッチの記録を1つの `.xlsx` にまとめて出力できます。「ストップウォッチ」列(名前)と「親子」列(親/子)が付き、画面表示と同じ並び順(親→その子たち→次の親…)で出力されます
- **画面ロック(固定)**: 画面右上に常時表示される小さな「固定」ボタンを押すと画面全体がロックされ(「固定中」表示・赤い枠)、ロックボタン自体以外はスタート/ストップやラップも含めて一切反応しなくなります。走りながらの計測などで誤タップを防ぎたいときに使います。もう一度ロックボタンを押すと解除されます
- **タップ時の振動**: どのボタンを押しても軽く振動します(対応端末のみ。iOS SafariはVibration API未対応のため振動しません)
- **押した感のある見た目**: iOSでは振動が出ない代わりに、指を触れた瞬間にボタンが少し縮んで暗くなり、押した感覚が伝わるようにしています
- **距離タブ(ペース計算)**: 画面上部の「距離」タブを開くと、距離(m)とタイムから1kmあたりのペースと時速を自動計算する表が使えます。タイムは秒(`270`)でも分:秒(`4:30`)でも入力可能。行は「+行を追加」で増やせ、各行の×ボタンで削除できます

## 使い方(ローカルで開く)

```bash
npx serve .
# または
python3 -m http.server 8080
```

ブラウザで表示された URL(例: `http://localhost:8080`)を開きます。`index.html` を直接ダブルクリックして `file://` で開いても動作します。

## ファイル構成

- `index.html` — 画面構造
- `style.css` — デザイン(記録を多列グリッドで密に表示)
- `app.js` — 計測ロジック・記録管理・Excel(.xlsx)出力(要インターネット接続。書き出し時にCDN経由でExcelJSライブラリを読み込みます)
- `icon.svg` / `icons/` — ファビコン・ホーム画面追加時のアイコン(ストップウォッチ型、画面はデジタル表示)
- `manifest.json` — ホーム画面に追加した際のアイコン・アプリ名の設定
