# ストップウォッチ Web アプリ

スタート・ラップ・ストップに対応したブラウザだけで動くストップウォッチです。
ラップボタンを押すたびに、区間タイム(直前のラップからの経過)と累計タイム(スタートからの経過)を同時に1件の記録として残し、密な一覧に並べます。たくさんの記録を一目で確認できるレイアウトです。記録は CSV への書き出し、または Google スプレッドシートへの直接保存に対応しています。

## 機能

- **スタート / ストップ**: 計測の開始・一時停止(ストップ後は再度スタートで再開、リセットでクリア)
- **ラップ**: 押すたびに、区間タイムと累計タイムを同時に1件の記録として追加
- **記録一覧**: 新しい順に、複数カラムの密なグリッドで表示。件数が増えても折り返して並ぶのでスクロールを最小限に一覧できます
- **CSV保存**: その場でCSVファイルとしてダウンロード(Excel/Googleスプレッドシートにインポート可能)
- **スプレッドシートに保存**: Google スプレッドシートへ直接、新しい記録だけを追記

## 使い方(ローカルで開く)

```bash
npx serve .
# または
python3 -m http.server 8080
```

ブラウザで表示された URL(例: `http://localhost:8080`)を開きます。`index.html` を直接ダブルクリックして `file://` で開いても動作します(スプレッドシート保存機能を含め、Google Cloud のオリジン制限は一切不要です)。

## Google スプレッドシート連携の設定(Google Apps Script)

Google Cloud プロジェクトや OAuth クライアントID の発行は不要です。保存先のスプレッドシートに直接紐づく Google Apps Script(GAS)をウェブアプリとして公開し、そのURLに向けて記録をPOSTする方式です。

1. **保存先のスプレッドシートを開く**(なければ新規作成)

2. **Apps Script エディタを開く**
   スプレッドシートのメニューから `拡張機能 → Apps Script`

3. **スクリプトを貼り付ける**
   このリポジトリの [`gas/Code.gs`](gas/Code.gs) の内容をエディタに貼り付けます。
   - `SECRET` の値を、他人に推測されないランダムな文字列に変更してください(アプリの設定画面で入力する「合言葉」と同じ値にします)
   - プロジェクト名をつけて保存

4. **ウェブアプリとしてデプロイ**
   右上の `デプロイ → 新しいデプロイ` → 種類の選択(歯車アイコン)で `ウェブアプリ` を選択
   - 実行するユーザー: **自分**
   - アクセスできるユーザー: **全員**
   - 「デプロイ」を押すと、初回のみ Google アカウントでのアクセス許可を求められます(自分のスプレッドシートにアクセスするための、あなた自身への確認です)。「詳細」→「(プロジェクト名)に移動」から許可してください
   - 発行された **ウェブアプリのURL**(`https://script.google.com/macros/s/xxxx/exec` の形式)をコピー

5. **アプリ側の設定**
   アプリ右上の ⚙ ボタンから設定画面を開き、以下を入力して保存します。
   - GAS ウェブアプリ URL(手順4でコピーしたもの)
   - 合言葉(手順3で設定した `SECRET` と同じ文字列)
   - シート名(既定は `シート1`。記録を書き込みたい実際のシート名に合わせて変更してください。存在しない場合は自動作成されます)
   - 「接続テスト」で正常につながるか確認できます

6. **保存**
   計測後、「スプレッドシートに保存」ボタンを押すと、まだ保存していない記録だけが末尾に追記されます(1行目が空ならヘッダー行も自動追加)。

設定値はブラウザの `localStorage` にのみ保存されます。

### セキュリティについて

ウェブアプリのアクセス設定を「全員」にするため、URLを知っていれば誰でもそのエンドポイントにリクエストを送れます。`SECRET` による簡易的なチェックはありますが、この値はブラウザ側のJavaScriptに含まれるため強固な認証ではありません。個人利用のスプレッドシート保存としては実用上十分ですが、機密性の高いデータの保護には向きません。デプロイ後にURLを他人に共有しないことをおすすめします。

## ファイル構成

- `index.html` — 画面構造
- `style.css` — デザイン(記録を多列グリッドで密に表示)
- `app.js` — 計測ロジック・記録管理・CSV/スプレッドシート連携
- `gas/Code.gs` — スプレッドシート側に貼り付ける Google Apps Script
