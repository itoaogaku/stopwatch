# ストップウォッチ Web アプリ

スタート/ストップ・ラップに対応したブラウザだけで動くストップウォッチです。
1つのタイマーに対して A・B 2つの独立したラップ系列を記録でき、押すたびに区間タイム(直前のラップからの経過)と累計タイム(スタートからの経過)を同時に1件の記録として残し、密な一覧に並べます。たくさんの記録を一目で確認できるレイアウトです。

## 機能

- **スタート/ストップ**: 1つのボタンで開始・一時停止をトグル(ストップ後は再度押して再開、リセットでクリア)
- **Aラップ / Bラップ / 両方**: 押すたびに、区間タイムと累計タイムを同時に1件の記録として追加。A・Bはそれぞれ独立したラップ回数・区間タイムを持ち、「両方」を押すとA・B両方の記録を同時に1件ずつ追加します(2人同時計測やダブルスプリットなどに利用できます)
- **記録一覧**: 新しい順に、複数カラムの密なグリッドで表示。A/Bのラベルが色分けされ、件数が増えても折り返して並ぶのでスクロールを最小限に一覧できます。通常は非表示で、A/B共通の「もっと見る」ボタン1つを押すと全件(両方まとめて)展開されます(もう一度押すと折りたたみます)
- **各レーンの最新ラップ**: 時計のLCD画面内、AとBそれぞれのライブタイム(直前のラップからの経過)の下に、そのストップウォッチ自身の直近の記録(区間タイム・合計タイム)が表示されます。他のストップウォッチの記録は表示されません。止まっている間は表示されません
- **子複製**: 「子複製」ボタンを押すと、そのストップウォッチの子として複製できます。計測中・停止中どちらでも、その時点の経過時間・A/Bの記録を丸ごと引き継ぎ(計測中ならそのまま動き続けます)、元の親のすぐ下に並びます(以降は互いに独立して操作可能。片方でラップしてももう片方には影響しません)。「削除」で不要になったストップウォッチを閉じられます(最後の1つは削除できません)
- **親子関係**: 「子複製」で増やしたストップウォッチは常に「子」になり、元のストップウォッチの親(すでに子ならそのルートの親)と同じカードの列に並びます(子をさらに子複製しても、同じ親の列にまとめて並びます)。子は本体・ボタンの色が紺色になり、一目で子だと分かります
- **横スライドでの切り替え**: 親とその子は縦に並ばず、同じ位置で横に並びます。左右にスワイプ(またはドラッグ)すると親↔子を切り替えられ、カード下部のドットで現在何番目を見ているか、他に何件あるかが分かります(ドットをタップしてジャンプすることも可能)。子がいない単独の親にはドットは表示されません
- **親複製**: 1番最初のストップウォッチにのみ表示されるボタンです。計測中でも、「親複製」ボタンを押すと記録・時計とも一切引き継がない、完全に新しい独立の「親」を追加できます(子にはならず、元のストップウォッチが動き続けていても影響しません)
- **名前の変更**: 各ストップウォッチ左上のラベル(親のデフォルトは作成順に A, B, C…Z, AA, AB…、子のデフォルトは親の名前を使って「A-複製1」「A-複製2」…)をタップ/クリックすると直接書き換えられます。空にするとそれぞれのデフォルトの名前に戻ります
- **Excel保存**: その場で罫線・太字ヘッダー付きの `.xlsx` ファイルとしてダウンロード(そのままExcel/Googleスプレッドシートで開けます)。ファイル名は `20260101_153042_stopwatch_1.xlsx` のように日付(YYYYMMDD)と時刻(HHMMSS)から始まります。ストップウォッチごとに個別に、「No」(ラップ番号)を基準にAの区間タイム・合計タイム、Bの区間タイム・合計タイムが縦の列で分かれて並びます(片方のレーンにしか記録がないラップ番号は該当列が空欄になります)。タイムは画面表示の1/100秒(例: `00:00.00`)ではなく、四捨五入した1/10秒で、先頭の単位(時間があれば時間、なければ分)の余分な0を省いた形(例: `8:12.5`、1時間以上なら `1:05:23.4`)で出力されます
- **全てExcel保存**: 1番最初のストップウォッチの「子複製」ボタンの左に並ぶボタンから、表示中の全ての親・子ストップウォッチの記録を1つの `.xlsx` にまとめて出力できます。「ストップウォッチ」列(名前)と「親子」列(親/子)が付き、画面表示と同じ並び順(親→その子たち→次の親…)で出力されます
- **画面ロック(固定)**: 画面右上に常時表示される小さな「固定」ボタンを押すと画面全体がロックされ(「固定中」表示・緑色の枠)、ロックボタン自体以外はスタート/ストップやラップも含めて一切反応しなくなります。走りながらの計測などで誤タップを防ぎたいときに使います。もう一度ロックボタンを押すと解除されます
- **タップ時の振動**: どのボタンを押しても軽く振動します(対応端末のみ。iOS SafariはVibration API未対応のため振動しません)
- **押した感のある見た目**: iOSでは振動が出ない代わりに、指を触れた瞬間にボタンが少し縮んで暗くなり、押した感覚が伝わるようにしています
- **タブの切り替え(メニュー)**: 画面左上の「☰」ボタンを押すと、計測・距離・山試走・ストレッチ・補強・TABATAの一覧が左からスライドインするメニューとして開きます。項目をタップするとそのタブに切り替わり、メニューは自動で閉じます。メニュー外(暗い背景部分)をタップするか、右上の「✕」でも閉じられます。現在どのタブを開いているかは、☰ボタンの右にある見出し(例:「ストレッチ」)に常に表示されます
- **距離タブ(ペース計算)**: 画面上部の「距離」タブを開くと、距離(m)とタイムから1kmあたりのペースと時速を自動計算する表が使えます。タイムは秒(`270`)でも分:秒(`4:30`)でも入力可能。行は「+行を追加」で増やせ、各行の×ボタンで削除できます
- **距離からの所要タイム早見表**: 同じ「距離」タブ内、距離(m)を入力した瞬間に、3:00/km〜4:00/kmの決まったペース(3:00, 3:10, 3:20, 3:24, 3:30, 3:36, 3:40, 3:42, 3:48, 3:50)と、4:00/km〜5:00/kmを10秒刻みで刻んだペース(4:00, 4:10, 4:20, 4:30, 4:40, 4:50, 5:00)ごとに、その距離を走るのにかかる時間が一覧で自動計算されます
- **山試走タブ(踏切安全チェック)**: 小涌谷駅⇄宮ノ下駅間の踏切について、上り(標高差による登り、宮ノ下→小涌谷方向の走行)・下り(小涌谷→宮ノ下方向の走行)それぞれで、スタートから踏切までのタイム(最速・最遅)と、その区間を走る電車の発着時刻(方向ごとに追加・削除可能)から、踏切に引っかかる可能性のある「スタートを避けるべき時間帯」と「安全にスタートできる時間帯」を検索範囲内で自動計算します。電車の閉鎖時間は、走る向きに関わらず、電車自体が小涌谷→宮ノ下方向なら「発-2分〜着-2分」、宮ノ下→小涌谷方向なら「発+1分〜着」として計算されます
- **ストレッチタブ(ストレッチカウントタイマー)**: 各種目30秒のストレッチメニューを、種目ごとに手動で進める専用タイマーです。「スタート」を押すとその種目の30秒カウントが始まり、画面には現在の種目名と経過タイムが表示されます。30秒のカウント中は大きな「次へ(スタート)」ボタンが「ストレッチ中」と表示されてロックされ、誤って次に進めないようになっています。30秒経過するとタイマーは自動で止まり(経過タイムが緑色に変化)、ボタンのロックも解除されて次の種目に進めるようになります。その上の「次は」欄で先の種目名とマネージャーが読み上げるセリフを事前に確認できます。車が来た時など計測を止めたい場合は「一時停止」でその場の経過タイムを保持したまま止められ、もう一度押すと再開します。「最初に戻す」でいつでも最初からやり直せます。ロック中でも押せる小さな「◀ 前に戻る」「次に進む ▶」ボタンがあり、種目を間違えて進めてしまったときにやり直したり、逆に不要な種目を飛ばして先に進めたりできます(「前に戻る」は最初の種目より前には戻れません)。各種目が始まるたびに、音声でセリフを自動読み上げし、30秒経って自動で止まった瞬間にも「終わり」と読み上げます(iOS Safariでも対応)。画面表示のセリフは元の資料通り(漢字+ふりがな+マネージャー向けの指示)ですが、読み上げ音声は筋肉名などをかな読みに変換し、ふりがなの二重読みや「選手が体制を変えたら〜」のような指示文は読まないようにしています。左上の「🔊 音声」ボタンで読み上げのON/OFFを切り替えられます(非対応端末では自動的に無効化されます)。その下の「声を選ぶ」から、この端末のブラウザが実際に読み上げに使える日本語音声を一覧表示し、選ぶとその場で試し読みされます(初期状態では名前に「Enhanced」「Premium」等が付く高品質な声を自動選択)。なお、iOS Safariでのブラウザの読み上げ(Web Speech API)は、設定アプリの「アクセシビリティ」→「読み上げコンテンツ」→「声」で選んだ声とは連動しません(あちらはVoiceOverなどOS機能専用の設定です)。声質を変えたい場合は、この「声を選ぶ」から選択してください
- **補強タブ(補強メニューカウントタイマー)**: ストレッチタブと同じ操作感で、補強メニューを種目ごとに手動で進める専用タイマーです。上部の「フル/コアA/コアB/ループ/下肢」ボタンでメニューを切り替えられます(現在は「フル」のみ内容があり、他は「このメニューは準備中です」と表示されます)。種目には、秒数が決まっているもの(例:ダイアゴナル40秒、L字腕振り60秒)と、回数・カウントだけで秒数が決まっていないもの(例:膝立て10回4カウント)があります。秒数が決まっている種目は、ストレッチタブと同様に自動でカウントして経過し、その秒数に達すると自動で止まって次に進めるようになります。回数・カウントだけの種目はロックされず、その場ですぐに「次へ」を押して進められます(何回数えるかはこの画面には表示される「10回4カウント」などの表記を参考に、マネージャーが判断します)。表示中の種目名の下に、その種目の回数・秒数(スペック)が小さく表示されます。「一時停止」「最初に戻す」、ロック中でも押せる「◀ 前に戻る」「次に進む ▶」、そしてセリフの自動読み上げ・自分の声での録音・チーム共有の仕組み自体はストレッチタブと同じですが、録音データはストレッチタブとは完全に別に保存されます(🔊音声のON/OFFだけは端末共通の設定です。「声を選ぶ」で選ぶ声・録音セット・録音一覧はストレッチタブと補強タブでそれぞれ独立しており、同じ「反対」でも別々に録音する必要があります)
- **セリフを自分の声で録音する・名前付きセットで管理・チームで共有**: ストレッチタブの「🎙 セリフを自分の声で録音する」・補強タブの同ボタンは、それぞれ完全に独立した録音一覧を開きます(モーダル右上のタイトルが「ストレッチの〜」「補強の〜」に変わります)。同じ「反対」という言葉でも、ストレッチ用と補強用は別々の録音として保存され、混ざりません。録音は種目ごとではなく、名前を付けた「セット」ごとにまとめて保存されます(例:コーチごとに1つずつセットを作って録音。セットもストレッチ・補強でそれぞれ独立しています)。モーダル上部の「セット」欄で、今どのセットを見ている/録音しているかを切り替えられます。「+ 新しいセット」で名前を入力すると新しいセットが作られ、以降そのセットに録音していきます。「🗑 セットを削除」でそのセット内の録音を全て削除できます(最初からある「個人利用音声」セットは削除できません)。一覧は種目ごとではなく、実際に読み上げる文言ごとにまとめられており、「反対」「終わり」のように同じタブ内の複数の種目で同じ文言を読む場合は1件にまとめて表示されます。各項目には「使用箇所: ○○(反対)、△△(反対)…」のようにどの種目で使われるかが表示されます。「🔴 録音」を押すとマイクの使用許可を求められ(初回のみ)、録音が始まります(ボタンは「⏹ 停止」に変化)。もう一度押すと録音が終わり、この端末に保存されると同時に、自動でチーム共有サーバーにもアップロードされます(初回のみ共有用の合言葉の入力を求められ、以降はこの端末に保存されて聞かれません)。ただし「個人利用音声」セットだけは例外で、録音してもこの端末に保存されるのみでチーム共有サーバーにはアップロードされません(名前付きセットを作ってそちらに録音すれば、これまで通りチームで共有できます)。「▶️ 再生」でその場で聞き直せ、「🗑 削除」でこの端末(と、共有されているセットなら共有サーバーも)から削除できます。各項目の状態は「未録音」「端末のみ(未共有)」(オフライン等でアップロードに失敗した場合)「端末に保存済み(共有なし)」(「個人利用音声」セットの場合)「チーム共有済み」のいずれかで表示されます。各タブの「声を選ぶ」の一覧には、音声合成の声(Kyokoなど)の下に、そのタブ用に存在するセットごとに「🎙 <セット名>」という選択肢が並びます(ストレッチ・補強で選ぶ声は別々に覚えられます)。これを選ぶと、以降の読み上げはそのセットの録音(この端末のものが無ければチームの録音)が使われ、そのセットに録音がないセリフだけ音声合成にフォールバックします。共有された録音は、録音していない他の端末・他の人でも(この画面を開くだけで)そのまま再生に使え、録音・マイクに対応していない端末でも再生だけは可能です。共有先は姉妹アプリ「トレーナー知見ライブラリ」(`itoaogaku/itonomaki`)がXserverの既存ホスティングに保存する仕組みを間借りしています。なお、この端末の録音自体はブラウザ内(IndexedDB)にも保存され、ページを閉じたり再読み込みしても残ります(共有サーバーと連携する前提のこの機能を除けば、アプリの他の部分は今まで通り何も保存されません)。補強タブ・セット機能導入前に録音したものは、ストレッチタブの「個人利用音声」セットとしてそのまま引き続き使えます
- **TABATAタブ**: 「スタート」を押すと、20秒のトレーニングと10秒のレストを自動で交互に繰り返す、8セット(合計4分)のタバタ形式インターバルタイマーです。手動操作は不要で、時間が来ると自動的に次のフェーズに進みます。トレーニング中は緑、レスト中は青緑色に画面全体が変わるので、離れていても一目でどちらのフェーズか分かります(対応端末では、フェーズが切り替わるたびに振動でも通知します)。8セット終了すると「完了!」と表示され、「もう一度」でリスタートできます。「リセット」でいつでも最初の状態に戻せます

## 使い方(ローカルで開く)

```bash
npx serve .
# または
python3 -m http.server 8080
```

ブラウザで表示された URL(例: `http://localhost:8080`)を開きます。`index.html` を直接ダブルクリックして `file://` で開いても動作します。

## ファイル構成

- `index.html` — 画面構造
- `style.css` — デザイン(記録を多列グリッドで密に表示)
- `app.js` — 計測ロジック・記録管理・Excel(.xlsx)出力(要インターネット接続。書き出し時にCDN経由でExcelJSライブラリを読み込みます)
- `icon.svg` / `icons/` — ファビコン・ホーム画面追加時のアイコン(ストップウォッチ型、画面はデジタル表示)
- `manifest.json` — ホーム画面に追加した際のアイコン・アプリ名の設定
